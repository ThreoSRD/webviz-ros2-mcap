# webviz-core

Application package for [Webviz ROS 2 MCAP](../../README.md), an independent derivative of Cruise Webviz.

Local MCAP input, ROS 2 CDR adaptation and the 3D/Plot/Image panels live here. Run installation,
development and verification commands from the repository root; this package is not published to npm
by this project. See the root README for supported formats and current limitations.

The original package README is preserved in [docs/upstream](../../docs/upstream/webviz-core-README.md).
