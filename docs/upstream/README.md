# Historical upstream material

These documents, CircleCI files and Dockerfiles are preserved from Cruise Webviz for provenance. They are not the current contribution policy, hosted service, CI or supported container recipes of Webviz ROS 2 MCAP.

In particular, the old Dockerfiles target Node versions that do not meet this project's current requirements. The active workflow is `.github/workflows/ci.yml`; local installation and build commands are in the root README. No upstream company credentials or hosting are required.
